# Model Preview Performance Baseline

Date: 2026-06-30

Command:

```powershell
npm run benchmark:model-preview
```

Benchmark fixtures are generated by `scripts/model-preview-benchmark.mjs` in a temporary resource pack:

- `simple`: 1 element, 1 texture.
- `parent-chain-8`: 8-model parent chain ending in a 4-element base model.
- `elements-500`: 500 elements, 1 texture.
- `generated-texture-alpha`: `item/generated` with a 32x32 PNG alpha/dimension read.

Results on this Windows workspace:

| Fixture | First IR | Hot Refresh |
| --- | ---: | ---: |
| simple | 10.182 ms | 2.086 ms |
| parent-chain-8 | 22.993 ms | 2.822 ms |
| elements-500 | 29.247 ms | 9.667 ms |
| generated-texture-alpha | 9.539 ms | 4.185 ms |

Notes:

- Hot refresh rebuilds preview IR after invalidating only the preview layer, so raw model, resolved model, and texture alpha/dimension caches are reused when file versions are unchanged.
- `elements-500` did not show enough blocking to justify chunked baking in this pass; cancellation checks now run at parse, resolve, generated-item, and bake element boundaries.
- Webview screenshot requests are guarded by a 10s host timeout, structured `screenshotError`, and dispose-time pending promise rejection.
- Webview resource release is covered by static self-checks for listener removal, resize observer disconnect, animation frame cancellation, renderer disposal, and WebGL context loss. Repeated open/refresh/close should be manually rechecked in an Extension Development Host before release packaging.
